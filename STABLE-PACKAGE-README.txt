Factorio 2.1.23 稳定版开服工具
================================

适用游戏版本：Factorio 2.1.23（当前稳定版）

使用方法：
1. 解压完整 ZIP，不要只从压缩包中单独运行 EXE。
2. 双击 FactorioServerManager.exe。
3. 工具会自动寻找 Steam Factorio、当前用户的存档和模组目录。
4. 选择 ZIP 存档，完成设置后点击“启动服务器”。

说明：
- 本稳定版专用包只接受 Factorio 2.1.23 的 factorio.exe。
- 服务器运行数据保存在 EXE 同目录的 runtime 文件夹，不会与本机游戏争用 .lock。
- 游戏、存档与模组不包含在发行包内。
- 服务器端口默认为 UDP 34197；内网穿透也应使用 UDP。
- 令牌、加入密码和 RCON 密码不会保存到 profile.json。
